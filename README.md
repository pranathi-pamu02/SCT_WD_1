# Interactive Landing Page | SkillCraft Technology

A professional, responsive landing page developed as part of the **SCT_WD_1** task for the Web Development internship at SkillCraft Technology.

## 🚀 Project Overview
This project demonstrates the core fundamentals of front-end development, focusing on clean UI/UX design, responsive layouts, and interactive elements.

## 🛠️ Tech Stack
* **HTML5:** Structured the content and layout.
* **CSS3:** Styled the page with a modern aesthetic and ensured responsiveness.
* **JavaScript (ES6):** Added interactivity (e.g., navigation effects, scroll animations, or form handling).

## ✨ Key Features
* **Responsive Design:** Fully optimized for mobile, tablet, and desktop views.
* **Interactive Navigation:** Smooth scrolling and dynamic header effects.
* **Modern UI:** Clean typography and a professional color palette.
